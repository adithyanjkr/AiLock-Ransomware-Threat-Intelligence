# AiLock Ransomware Threat Intelligence Investigation

A passive Cyber Threat Intelligence (CTI) investigation into an AiLock-branded ransomware leak site.

## Objectives
- Analyze publicly visible ransomware victim listings.
- Document alleged data exposure claims.
- Correlate observations with public threat intelligence.
- Assess the reliability of ransomware claims.

## Key Observation
An AiLock-branded leak site listed Richmont Graduate University as an alleged victim and advertised a ZIP archive named `richmont.lst.zip` (511 KB).

The archive was not downloaded or accessed.

## Investigation Scope
- Passive observation
- Public threat intelligence research
- Evidence documentation
- Ransomware claim assessment

## Evidence
Screenshots of the victim listing and advertised archive are available in the `evidence/` directory.

## Disclaimer
The listing was observed, but the alleged breach and data exposure remain unverified.

This project is intended for educational and defensive cybersecurity research.
