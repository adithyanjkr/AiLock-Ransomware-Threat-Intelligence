# 🔍 AiLock Ransomware Threat Intelligence Investigation

A passive Cyber Threat Intelligence (CTI) investigation into an AiLock-branded ransomware leak site.

## Objectives
- Analyze publicly visible ransomware victim listings.
- Document alleged data exposure claims.
- Correlate observations with public threat intelligence.

## Investigation Summary
During passive observation, a listing for **Richmont Graduate University** was found on an AiLock-branded leak site.

A file archive was advertised for download. The download prompt was documented, but the archive was **not downloaded or accessed**.

## Evidence
Screenshots and evidence notes are available in the [`evidence/`](evidence/) directory.

- `listing.png` — Victim listing
- `download-prompt.png` — Advertised archive download prompt

## Important Note
This investigation documents publicly visible claims only. The screenshots do **not** independently confirm a successful breach or data theft. No victim data is included in this repository.

## Methodology
- Passive observation
- Screenshot documentation
- Evidence organization
- Threat intelligence assessment
